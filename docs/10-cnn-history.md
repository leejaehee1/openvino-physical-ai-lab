# 10. [보충] MNIST에서 ResNet까지 — 이미지 인식 모델의 변천사

> 보충 이론입니다 (약 2차시). M2에서 가져다 쓴 분류 모델, M3에서 학습한 YOLO, M5의 ACT 안에 들어 있는 ResNet이 **어디서 왔는지** 한 줄로 이어 봅니다.
> 각 모델이 "앞 모델의 어떤 문제를 풀었나"에 집중하면 외울 것이 거의 없습니다.

## 학습 목표

- MNIST → LeNet → AlexNet → VGG → GoogLeNet → ResNet으로 이어지는 흐름을 **문제와 해결** 의 쌍으로 설명할 수 있다.
- 합성곱(CNN)이 이미지에 잘 맞는 이유를 말할 수 있다.
- ResNet의 **숏컷 연결** 이 왜 깊은 모델을 가능하게 했는지, GPT(09)·ACT와 어떻게 이어지는지 안다.
- 엣지용 경량 모델(MobileNet 등)이 등장한 이유를 우리 노트북 환경과 연결해 설명할 수 있다.

## 1. 출발점 — 왜 이미지에는 합성곱인가

이미지 한 장(224×224 컬러)은 숫자 약 15만 개입니다. 이것을 모든 숫자끼리 연결하는 일반 신경망(완전 연결층)에 넣으면 연결이 너무 많아지고, "고양이가 왼쪽에 있든 오른쪽에 있든 고양이"라는 사실도 따로따로 배워야 합니다.

**합성곱(convolution)** 은 작은 필터(예: 3×3)를 이미지 위에서 미끄러뜨리며 같은 패턴을 찾습니다.

| 성질 | 의미 | 왜 좋은가 |
|---|---|---|
| **지역 연결** | 필터는 주변 몇 칸만 봄 | 가까운 픽셀끼리 관련 있다는 이미지의 성질과 맞음 |
| **가중치 공유** | 같은 필터를 이미지 전체에 재사용 | 파라미터가 크게 줄고, 위치가 달라도 같은 패턴을 찾음 |
| **층 쌓기** | 얕은 층은 선·모서리, 깊은 층은 부분·물체 | 단순한 특징을 조합해 복잡한 특징을 만듦 |
| **풀링** | 영역마다 대표값만 남김 | 크기를 줄여 계산을 아끼고, 조금 움직여도 결과가 같게 |

> 합성곱 계산을 손으로 따라가 보는 예제는 [대학원 노트 — Computer Vision과 CNN](https://leejaehee1.github.io/graduate-study/artificial-intelligence/04-YOLO)에 있습니다.

## 2. 1998 — MNIST와 LeNet-5: CNN의 시작

### MNIST

| 항목 | 내용 |
|---|---|
| 내용 | 손으로 쓴 숫자 0–9 |
| 크기 | 28×28 흑백 |
| 규모 | 학습 60,000장, 테스트 10,000장 |
| 의미 | 딥러닝의 **"Hello, World"**. 지금도 새 아이디어를 가장 먼저 시험하는 데이터셋 |

### LeNet-5 (LeCun 등, 1998)

```text
입력 32×32 → [합성곱 → 풀링] → [합성곱 → 풀링] → 완전 연결 → 완전 연결 → 숫자 10개 점수
```

- **합성곱 → 풀링 → 합성곱 → 풀링 → 분류** 라는, 지금까지 이어지는 CNN의 기본 골격을 만들었습니다.
- 파라미터는 약 **6만 개**. 실제로 은행 수표의 숫자를 읽는 데 쓰였습니다.
- **핵심 변화**: 특징(선, 곡선)을 사람이 설계하지 않고 **데이터에서 필터를 학습** 했습니다.

**그런데 왜 10년 넘게 조용했나?** 숫자처럼 작고 단순한 이미지는 잘했지만, 실제 사진을 인식하기에는 **데이터도, 계산력도 부족** 했습니다.

## 3. 2009–2012 — ImageNet, 그리고 AlexNet의 충격

### ImageNet과 ILSVRC

- **1,000개 클래스, 약 120만 장** 의 학습 이미지로 진행된 대규모 이미지 인식 대회(2010–2017).
- 평가 지표는 주로 **Top-5 오류율**: 모델이 고른 상위 5개 답 안에 정답이 없으면 틀린 것으로 칩니다.

### AlexNet (Krizhevsky, Sutskever, Hinton, 2012)

2012년 대회에서 Top-5 오류율 **약 15%** 를 기록했습니다. 2위(약 26%, 사람이 설계한 특징 방식)와 **10%p 넘게** 차이가 났고, 이 사건을 계기로 컴퓨터 비전 전체가 딥러닝으로 넘어갔습니다.

| AlexNet의 무기 | 효과 | 지금도 쓰나? |
|---|---|---|
| **GPU 학습** (GPU 2장) | 몇 주 걸릴 학습을 현실적인 시간으로 | 학습의 표준 (우리 B70) |
| **ReLU** 활성화 | 깊어져도 학습이 빠르고 잘 됨 | 기본 활성화 함수 (LLM은 GELU, 09) |
| **드롭아웃** | 과대적합 감소 | 여전히 사용 (09의 GPT에도) |
| **데이터 증강** (자르기, 뒤집기) | 같은 데이터로 더 다양하게 학습 | 표준 (M3 YOLO 증강) |

구조는 합성곱 5층 + 완전 연결 3층, 파라미터 약 **6,000만 개** 로 LeNet보다 1,000배 큽니다.

> **교훈**: 아이디어(CNN)는 1998년에 이미 있었습니다. 2012년에 달라진 것은 **대규모 데이터(ImageNet) + 계산력(GPU)** 이었습니다. 우리가 13일차에 데이터와 B70 GPU를 그렇게 신경 쓴 것과 같은 이야기입니다.

## 4. 2014 — VGG: 작은 필터를 깊게

AlexNet은 층마다 필터 크기(11×11, 5×5, 3×3)가 제각각이었습니다. VGG(Simonyan & Zisserman, 2014)는 **"3×3 합성곱만 써서 깊게 쌓자"** 는 단순한 규칙으로 16층(VGG16)·19층(VGG19)을 만들었습니다.

### 왜 3×3 두 번이 5×5 한 번보다 나은가

| | 5×5 한 번 | 3×3 두 번 |
|---|---|---|
| 한 번에 보는 범위 | 5×5 | 5×5 (같음) |
| 파라미터 (채널 C → C) | 25·C² | 9·C² × 2 = **18·C²** |
| 비선형(ReLU) 횟수 | 1번 | **2번** (더 복잡한 패턴 표현) |

3×3 세 번이면 7×7 범위를 49·C² 대신 27·C²로 봅니다. **같은 범위를 더 적은 파라미터로, 더 깊게** 보는 것입니다.

### 크기 변화 (VGG16)

```text
224×224×3 → 64채널 → 풀링 112 → 128채널 → 56 → 256채널 → 28 → 512채널 → 14 → 512채널 → 7×7×512
          → 완전 연결 4096 → 4096 → 1000개 클래스
```

가로·세로는 절반씩 줄고 채널은 두 배씩 늘어납니다. **"어디에"는 압축하고 "무엇이"는 풍부하게** 만드는 CNN의 전형적인 모양입니다.

### VGG의 약점 — 무겁다

VGG16의 파라미터는 약 **1억 3,800만 개** 인데, 그중 첫 완전 연결층 하나(7×7×512 → 4096)만 약 **1억 300만 개** 입니다. 구조가 단순해 이해하기 쉽고 특징 추출기로 오래 쓰였지만, **엣지에서 돌리기에는 너무 무겁습니다**.

## 5. 2014 — GoogLeNet (Inception): 넓게, 하지만 가볍게

같은 해 대회 우승은 GoogLeNet(Szegedy 등, 2014)이었습니다. 22층으로 VGG보다 깊은데 파라미터는 **약 700만 개** 로 VGG의 20분의 1 수준입니다.

| 아이디어 | 내용 |
|---|---|
| **Inception 모듈** | 1×1, 3×3, 5×5 합성곱과 풀링을 **나란히** 돌려 결과를 합침. 필터 크기를 고민하지 말고 모델이 고르게 함 |
| **1×1 합성곱** | 위치는 그대로 두고 **채널 수만 줄이는** 압축 장치. 무거운 3×3·5×5 앞에 두어 계산량을 크게 줄임 |
| **완전 연결층 축소** | 마지막에 평균 풀링으로 바로 분류 → VGG의 거대한 완전 연결층이 없음 |

> 1×1 합성곱은 이후 ResNet, MobileNet, YOLO 등 거의 모든 모델에 들어가는 기본 부품이 됩니다.

## 6. 2015 — ResNet: 깊게 쌓으면 나빠지는 문제를 풀다

### 6-1. 이상한 현상 — 깊을수록 오히려 나쁘다

VGG의 교훈대로 층을 더 쌓으면 더 좋아질 것 같지만, 실제로는 20층 모델보다 56층 모델이 **학습 데이터에서조차** 오류가 더 높았습니다. 과대적합(학습은 잘되고 테스트만 나쁨)이 아니라, **깊은 모델이 아예 잘 학습되지 않는** 문제였습니다.

### 6-2. 해결 — 숏컷 연결 (He 등, 2015)

```text
        x ─────────────────────┐ (그대로 건너뜀)
        │                      │
        ▼                      │
   [합성곱 → BN → ReLU → 합성곱 → BN]   = F(x)
        │                      │
        ▼                      ▼
        └──────── 더하기 ◀──────┘
                   │
              출력 = F(x) + x
```

- 블록이 **입력 x를 그대로 출력에 더합니다**. 블록은 "전체 답"이 아니라 **"x에서 얼마나 고칠지(잔차, residual)"** 만 배우면 됩니다.
- 고칠 게 없으면 F(x)를 0으로 만들면 그만이라, 층을 더 쌓아도 **최소한 나빠지지는 않습니다**.
- 역전파 때 학습 신호가 더하기 경로를 타고 **앞쪽 층까지 줄지 않고** 전달됩니다.

결과: **152층** ResNet으로 2015년 대회 우승, Top-5 오류율 **약 3.6%** — 사람의 오류율로 자주 인용되는 약 5%보다 낮은 수치였습니다.

| 버전 | 층 수 | 파라미터 (대략) | 어디서 보나 |
|---|---|---|---|
| ResNet-18 | 18 | 약 1,170만 | **ACT의 이미지 백본** (M5) |
| ResNet-50 | 50 | 약 2,560만 | M2 사전학습 분류 모델의 단골 |
| ResNet-152 | 152 | 약 6,000만 | 2015 대회 우승 |

### 6-3. 숏컷 연결은 어디로 이어졌나

| 모델 | 숏컷 연결의 모습 |
|---|---|
| **GPT (09)** | 트랜스포머 블록마다 "입력 + 어텐션 결과", "입력 + 피드 포워드 결과" |
| **ACT (M5)** | ResNet-18 백본 + 트랜스포머 블록 모두 숏컷 사용 |
| **YOLO (M3)** | 백본 곳곳의 잔차 블록 |

> **ResNet의 숏컷 연결은 CNN만의 기술이 아니라, 깊은 신경망 전체의 기본 설계가 되었습니다.** 09에서 본 GPT의 "숏컷 연결"이 바로 이것입니다.

함께 등장한 **배치 정규화(Batch Normalization, 2015)** 도 층마다 값의 분포를 맞춰 깊은 모델의 학습을 안정시켰습니다. (GPT는 비슷한 목적으로 층 정규화를 씁니다.)

## 7. 2017 이후 — 정확도에서 효율로: 엣지를 위한 CNN

ResNet 이후 "더 정확하게"만큼 중요해진 질문이 **"휴대폰·카메라·로봇에서 돌아가는가"** 입니다.

| 모델 | 핵심 아이디어 | 효과 |
|---|---|---|
| **MobileNet** (2017) | **깊이별 분리 합성곱**: 공간 방향(채널마다 3×3)과 채널 방향(1×1)을 나눠 계산 | 3×3 합성곱 계산량을 대략 8–9분의 1로 |
| MobileNetV2 (2018) | 좁게 → 넓게 → 좁게 + 숏컷 (역잔차 블록) | 더 가볍고 정확하게 |
| **EfficientNet** (2019) | 깊이·너비·입력 해상도를 **균형 있게 함께** 키우는 규칙 | 같은 계산량에서 더 높은 정확도 |

### 깊이별 분리 합성곱을 숫자로

입력 채널 C, 출력 채널 C′, 필터 3×3일 때 한 위치의 곱셈 수:

| 방식 | 곱셈 수 | C = C′ = 256일 때 |
|---|---|---|
| 일반 합성곱 | 9 · C · C′ | 589,824 |
| 깊이별 분리 (3×3 깊이별 + 1×1) | 9 · C + C · C′ | 67,840 (약 **8.7분의 1**) |

> **우리 과정과의 연결**: M2에서 CPU·GPU·NPU 속도를 비교하고 INT8로 양자화한 것, M4에서 LLM을 INT4로 압축한 것 모두 같은 방향입니다. **모델 구조를 가볍게(MobileNet) + 숫자를 가볍게(양자화) + 실행을 빠르게(OpenVINO)** 가 엣지 AI의 세 갈래입니다.

## 8. 2020 — ViT: 이미지를 토큰으로

**Vision Transformer**(Dosovitskiy 등, 2020)는 이미지를 16×16 조각으로 잘라 **각 조각을 토큰처럼** 취급하고, 09에서 본 트랜스포머에 넣습니다.

| | CNN | ViT |
|---|---|---|
| 기본 연산 | 합성곱 (주변만 봄) | 셀프 어텐션 (모든 조각을 서로 참고) |
| 잘하는 조건 | 데이터가 적당해도 잘 학습 | 데이터가 아주 많을 때 강함 |
| 지금 | 엣지·실시간 검출의 주력 (YOLO 등) | 대형 비전 모델, VLM·VLA의 이미지 인코더 |

M4의 VLM과 SmolVLA·Pi0.5 같은 VLA의 "눈" 부분에는 이런 트랜스포머 계열 이미지 인코더가 많이 쓰입니다. 반면 ACT는 **가볍고 검증된 ResNet-18** 을 눈으로 씁니다. **엣지에서 무엇을 고를지는 정확도와 속도의 균형** 입니다.

| 우리가 쓴 것 | 이 계보의 어디인가 |

| M2 사전학습 분류 모델 | ResNet·MobileNet 계열 + ImageNet 사전학습 |

| M3 Anomalib | ImageNet으로 사전학습된 CNN의 **특징** 을 빌려 정상과 다른 부분을 찾음 |
| M4 VLM | 트랜스포머 계열 이미지 인코더 + LLM |
| M5 ACT | **ResNet-18**(눈) + 트랜스포머(판단·동작) |
| M2·M4·M5 OpenVINO | 어떤 계보의 모델이든 CPU·GPU·NPU에서 가볍게 실행 |

> **한 줄 정리**: LeNet이 "필터를 학습하자"를, AlexNet이 "데이터와 GPU면 된다"를, VGG가 "작게 깊게"를, GoogLeNet이 "1×1로 가볍게"를, ResNet이 "숏컷으로 더 깊게"를, MobileNet이 "엣지에서도"를 남겼습니다. 우리 로봇의 눈(ACT의 ResNet-18)에는 이 모든 것이 들어 있습니다.

## 10. 자기점검

1. 일반 신경망 대신 합성곱을 쓰면 무엇이 좋은가요? (두 가지 이상)

5. GoogLeNet에서 1×1 합성곱은 어떤 역할을 하나요?
6. ResNet 이전에 층을 깊게 쌓으면 생긴 문제와, 숏컷 연결이 그것을 푼 방법은?
7. 숏컷 연결은 GPT와 ACT 중 어디에 쓰이나요?
8. MobileNet이 등장한 이유를 우리 노트북 환경과 연결해 설명해 보세요.

<summary>모범 답안</summary>

1. 필터가 주변만 보므로(지역 연결) 연결 수가 적고, 같은 필터를 이미지 전체에 재사용하므로(가중치 공유) 파라미터가 줄며 위치가 달라도 같은 패턴을 찾습니다. 층을 쌓으면 단순한 특징에서 복잡한 특징으로 올라갑니다.
2. 실제 사진을 학습할 만큼 큰 데이터(ImageNet)와 깊은 모델을 학습시킬 계산력(GPU)이 2012년에야 갖춰졌기 때문입니다. ReLU, 드롭아웃, 데이터 증강 같은 기법도 함께 작용했습니다.
3. 보는 범위는 같은데 파라미터는 25C²에서 18C²로 줄고, ReLU를 두 번 거쳐 더 복잡한 패턴을 표현할 수 있습니다.
4. 마지막 완전 연결층, 특히 첫 번째(7×7×512 → 4096)에 약 1억 300만 개가 몰려 있습니다.
5. 위치는 그대로 두고 채널 수를 줄여, 뒤에 오는 무거운 합성곱의 계산량을 크게 줄입니다.
6. 학습 데이터에서조차 깊은 모델의 오류가 더 높아지는(학습이 잘 안 되는) 문제가 있었습니다. 숏컷 연결은 입력을 출력에 더해 블록이 "고칠 부분"만 배우게 하고, 학습 신호가 앞쪽 층까지 잘 전달되게 합니다.
7. 둘 다입니다. GPT의 트랜스포머 블록과 ACT의 ResNet-18 백본·트랜스포머 모두 숏컷 연결을 씁니다.
8. 큰 모델은 노트북·휴대폰·로봇 같은 엣지 기기에서 너무 느리거나 메모리가 부족합니다. MobileNet은 깊이별 분리 합성곱으로 계산량을 크게 줄여, 16GB 노트북의 CPU·iGPU·NPU에서도 실시간으로 돌 수 있게 만든 방향의 대표입니다.

## 용어 사전

| 용어 | 뜻 |
|---|---|
| 합성곱 (convolution) | 작은 필터를 이미지 위에서 움직이며 곱해 더해 특징을 찾는 연산 |
| 필터 (커널) | 합성곱에 쓰는 작은 가중치 묶음. 학습으로 값이 정해짐 |
| 풀링 | 영역마다 대표값(최댓값·평균)만 남겨 크기를 줄이는 연산 |
| 채널 | 한 위치에 있는 특징의 종류 수 (컬러 입력은 3, VGG 깊은 층은 512) |
| Top-5 오류율 | 상위 5개 예측 안에 정답이 없는 비율 |
| ReLU | 0보다 작으면 0, 크면 그대로 내보내는 활성화 함수 |
| 드롭아웃 | 학습 중 일부 값을 무작위로 0으로 만들어 과대적합을 줄이는 기법 |
| 데이터 증강 | 자르기·뒤집기 등으로 학습 데이터를 다양하게 늘리는 기법 |
| 1×1 합성곱 | 위치는 그대로 두고 채널 수를 바꾸는 합성곱 |
| 숏컷 연결 (잔차 연결) | 블록의 입력을 출력에 더하는 지름길. ResNet의 핵심 |
| 배치 정규화 | 층마다 값의 분포를 맞춰 학습을 안정시키는 기법 |
| 백본 (backbone) | 이미지에서 특징을 뽑는 앞부분 네트워크 (예: ACT의 ResNet-18) |
| 깊이별 분리 합성곱 | 공간 방향과 채널 방향 계산을 나눠 계산량을 줄인 합성곱 (MobileNet) |
| ViT | 이미지를 조각 토큰으로 잘라 트랜스포머로 처리하는 모델 |
