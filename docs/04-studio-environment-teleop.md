# 04. Studio 환경 구성과 텔레오퍼레이션 (93–96차시)

## 학습 목표

- Studio의 프로젝트 · 로봇 · 카메라 · 환경 · 데이터셋 · 모델의 관계를 이해한다.
- 카메라를 반 공통 기준으로 등록하고 환경(Environment)을 만든다.
- 리더 팔로 팔로워를 원격조작(텔레오퍼레이션)하고, 녹화할 작업을 연습한다.

## 1. Studio의 구성 요소

```text
프로젝트 (class_pick)
 ├── 로봇:   follower_03 (SO101 Follower), leader_03 (SO101 Leader)
 ├── 카메라: front (USB, 640×480, 30fps)
 ├── 환경:   env_03  =  팔로워 + 리더 + 카메라 묶음
 ├── 데이터셋: s05_pick  ← 환경을 골라서 녹화
 └── 모델:   ACT 학습 결과 ← 데이터셋을 골라서 학습
```

**환경(Environment)** 이 핵심입니다. "어떤 로봇과 어떤 카메라로 녹화·추론하는가"를 한 묶음으로 저장해 두고, 녹화할 때도 추론할 때도 같은 환경을 씁니다.

## 2. 카메라 등록

**Cameras(카메라)** 메뉴 → Add camera(카메라 추가)

| 항목 | 우리 반 기준 |
|---|---|
| 이름 | `front` (손목 카메라를 쓰면 `gripper`) — **철자·대소문자까지 반 전체 동일** |
| 해상도 | 640 × 480 |
| fps | 30 |

- 장치를 고른 뒤 **미리보기가 올바른 카메라인지** 확인하고 저장합니다. (노트북 내장 웹캠과 헷갈리기 쉬움)
- 해상도를 높여도 모델은 내부에서 이미지를 줄여 쓰므로 성능 이득은 없고 용량만 커집니다.

> 왜 이름까지 똑같아야 하나요? 내일 반 전체 데이터를 하나로 합쳐 학습합니다. 데이터 안에서 카메라는 이름(`observation.images.front`)으로 구분되므로, 한 명이라도 `Front`나 `cam1`로 등록하면 병합이 실패합니다.

## 3. 환경 만들기

**Environments(환경)** 메뉴 → New environment(새 환경)

1. 팔로워: `follower_XX`
2. 텔레오퍼레이터(리더): `leader_XX`
3. 카메라: `front` (+ `gripper`)
4. 저장 → 환경을 열어 로봇과 카메라가 모두 보이는지 확인

## 4. 텔레오퍼레이션

환경 화면에서 원격조작을 시작합니다.

1. **두 팔 주변을 비웁니다.** 시작하는 순간 팔로워가 리더 자세로 이동합니다.
2. 리더를 팔로워와 비슷한 자세로 둔 상태에서 시작하면 급격한 움직임이 줄어듭니다.
3. 리더 손잡이를 잡고 천천히 움직이며 팔로워가 따라오는지 확인합니다.
4. 트리거로 그리퍼를 열고 닫아 봅니다.

### 연습 과제 (조별 10분)

- 각 관절을 하나씩만 움직여 보기 (어느 모터가 어느 관절인지 몸으로 익히기)
- 작업 물체를 집어서 상자에 넣어 보기 — **내일 녹화할 동작을 미리 연습**
- 짝꿍과 역할 교대: 한 명은 조작, 한 명은 물체 리셋

## 5. 작업대 고정 — 내일 녹화 품질을 결정

모방학습 모델은 **녹화할 때 본 장면과 비슷해야** 잘 동작합니다. 그리고 내일은 반 전체 데이터를 합치므로, 조마다 배치가 다르면 모델이 헷갈립니다.

| 고정할 것 | 방법 |
|---|---|
| 로봇 베이스 위치 | 바닥 테이프로 베이스 모서리 표시 (클램프로 고정하면 더 좋음) |
| 물체 시작 위치 | 테이프로 X 표시 |
| 목표 위치(상자) | 테이프로 테두리 표시 |
| 카메라 위치·각도 | 테이프 표시 + 화면에 로봇·물체·상자가 모두 들어오는지 확인 |
| 조명 | 창가 직사광선 피하기, 가능하면 블라인드 |

## 6. 2인 1로봇 — 짝꿍 노트북으로 넘기기

오늘 안에 **두 노트북 모두** 텔레오퍼레이션까지 되어야 내일 각자 녹화할 수 있습니다.

```bash
# 내 노트북
docker compose down
# (USB 케이블 2개 + 카메라를 짝꿍 노트북으로)
# 짝꿍 노트북
docker compose up -d
```

짝꿍 노트북에서는 로봇 등록 시 **"Skip verification"** 으로 보드에 저장된 캘리브레이션을 읽어옵니다. 카메라·환경 이름은 같은 규칙으로 등록합니다.

## 더 해보기 (경험자)

- 텔레오퍼레이션 중 로봇 패널의 관절값 그래프를 보며, 리더와 팔로워 값이 얼마나 차이 나는지(추종 지연) 관찰
- 카메라 fps를 15로 바꿔 보고 영상의 끊김 차이 확인 (확인 후 30으로 되돌리기)
- `application/docs/explanation/runtime-session-architecture.md`를 읽고 Studio가 로봇 세션을 어떻게 관리하는지 정리

## 체크포인트

- [ ] 카메라 이름·해상도·fps가 반 기준과 같다
- [ ] 환경을 열면 팔로워·리더·카메라가 모두 보인다
- [ ] 리더로 팔로워를 움직여 물체를 상자에 넣을 수 있다
- [ ] 짝꿍 노트북에서도 텔레오퍼레이션이 된다
- [ ] 작업대에 테이프 표시를 마쳤다
